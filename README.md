React-приложение для управления списком имён с возможностью редактирования, удаления и добавления в избранное.

Функционал
Приложение позволяет:
* Добавлять имена
* Удалять имена
* Редактировать имена
* Добавлять/удалять из избранного
* Считать общее количество имён

Логика работы
* Используется React и хук useState
* Все данные хранятся в состоянии (state)
* Есть защита от:
    * пустых значений
    * дубликатов
